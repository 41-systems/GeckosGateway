🦎 Gecko's Gateway

Network Reconnaissance & Security Tools — Built with a Little Help from SHODAN

Welcome to Gecko's Gateway, a collection of network and security utilities wrapped in a deliberately retro, MS Paint-inspired interface featuring our resident gecko.

These tools were created and refined with the help of AI and are designed to make common network-security and reconnaissance tasks easier to explore from a single dashboard.

🖥️ What's Inside

⚡ DNS & Provider Trace — Explore DNS information, resolver behavior, network details, and upstream infrastructure.

🌐 IP Information — Inspect public IP, ASN, ISP, geographic, and network information.

📋 WHOIS / RDAP — Look up publicly available domain registration and nameserver information.

🔌 Port Scanner — Perform limited connectivity checks against authorized systems and common service ports.

🔍 Browser Fingerprint — Examine browser and device signals exposed to the web.

🔑 Password Generator — Create cryptographically secure passwords and customizable passphrases.

🦎 Why the Gecko?

Because security tools don't have to look boring.

Gecko's Gateway combines useful network-security concepts with a deliberately crude MS Paint / old-school computer lab aesthetic. Think retro graphics, green-screen terminals, chunky buttons, and a gecko in overalls doing network reconnaissance.

Built for learning. Built for experimentation. Built with SHODAN.

Use these tools responsibly and only against systems, networks, and domains you own or have explicit permission to test.
